DOCKER COMMANDS
| --------------------------------------- | ---------------------------------------- |
| Command                                 | Purpose                                  |
| --------------------------------------- | ---------------------------------------- |
| `docker pull localstack/localstack:3.5` | Download LocalStack image                |
| `docker compose up -d`                  | Start LocalStack container in background |
| `docker logs localstack`                | View LocalStack logs                     |
| `docker compose down`                   | Stop and remove running containers       |
| `docker ps`                             | Show running containers                  |
| `docker ps -a`                          | Show all containers (including stopped)  |
| `docker images`                         | Show downloaded Docker images            |
| `docker rmi IMAGE_ID`                   | Delete image                             |
| `docker rm CONTAINER_ID`                | Delete container                         |
| --------------------------------------- | ---------------------------------------- |
